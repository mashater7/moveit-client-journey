# Move IT · Исследование и план сайта

Рабочая презентация для заказчика: факты о компании, наблюдения исследования рынка, предлагаемое позиционирование, структура сайта и вопросы перед разработкой. Для небольшого и крупного офиса отдельно разобраны сильные стороны, акценты, восемь блоков сайта и порядок после обращения. Каждый блок связывает вопрос посетителя с возражением, содержанием, подтверждениями и следующим шагом. Пример формы работает без отправки данных.

Открыть `index.html` или запустить любой статический HTTP-сервер из этой папки. Сборка и установка пакетов не нужны.

Содержание подготовлено на основе ответов клиента и предоставленной презентации объектов. Все интерфейсы, тексты экранов и действия после заявки — предложения для обсуждения. Спорные тарифы и неподтверждённые гарантии не используются. Исходные клиентские документы в репозиторий не включены.

Технологии: HTML, CSS, vanilla JavaScript. Никаких внешних запросов, трекеров, сбора контактов или backend. Для GitHub Pages: branch `main`, folder `/ (root)`.
